# man-utd-recruitment-analysis

# Data-Driven Football Recruitment: Building a Recruitment Analytics Platform for Professional Football
# Case Study: Manchester United – Defensive Controller Recruitment

## Project Overview

This project demonstrates how football analytics can support evidence-based recruitment decisions within a professional football environment.

Using publicly available performance data from the Top Five European leagues, the project evaluates Manchester United's midfield requirements and develops a role-specific recruitment model to identify players who best fit the profile of a Defensive Controller.

Rather than simply ranking players using generic statistics, the project follows a structured recruitment methodology by translating tactical requirements into measurable performance indicators, engineering role-specific metrics and generating data-driven transfer shortlists through interactive visualisations.

The objective is not to replace traditional scouting, but to demonstrate how data can complement recruitment by identifying suitable candidates, supporting decision-making and improving the efficiency of the scouting process.
